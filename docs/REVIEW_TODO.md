# repo-nanj-thread レビュー指摘台帳

`plugins/repo-nanj-thread/skills/repo-nanj-thread/` に対するプロンプト技法レビューの指摘 42 件について、採否と適用状況を管理する台帳。

## 運用方針

- 「適用待ち」の項目は、Claude Code が推奨で判断し、適用・台帳更新・commit まで進めてよい。
- 「判断待ち」の項目も同様に進めてよい。
- ただし作者が置いた数値（設計値）については、理由を推測で書かない。「根拠は未記録」と明記する形で処理する。
- 判断の根拠は、現物・公式ドキュメント・台帳の記述に基づくこと。推測を根拠として書かない。

### 性質

| 性質 | 意味 |
|---|---|
| 文体 | 否定形・理由なき「必ず」など、中身が変わらない書き換え |
| 削除判断 | 行や節の削除・層の一本化を含む |
| 仕様判断 | 完了条件・上限・処理経路など設計に関わる |
| 設計値 | 作者本人が値を置いた箇所で、理由の記述が必要なもの |

### 状態

| 状態 | 意味 |
|---|---|
| 適用済 | 採用し、ファイルに反映した |
| 完了 | 論点について、実測や確認によって決着した |
| 未採否 | 採否を決めていない |
| 保留 | 他の指摘の採否待ち |
| 不採用 | 採否の判断を経て採らなかった |
| 終端行 | （完了・適用待ち・判断待ちでは使わない。末尾の論点一覧のみ） |
| 該当なし | レビュー時点で該当なしと判定した |
